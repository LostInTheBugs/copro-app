PROPRIETAS — WINDOWS VERSION (desktop application)
==================================================

What is it?
  Proprietas is a co-ownership (condominium) management application for
  volunteer property managers. This Windows version is self-contained: the
  server and the interface are bundled in the folder — nothing else to
  install, no internet connection required. Your data stays on this
  computer.

Installation
  1. Unzip the « Proprietas » folder wherever you like (e.g. Documents).
  2. Double-click « Proprietas.exe » — the window opens.
  3. On first launch, create your manager account (« Premier compte
     (syndic) » tab). The interface is in French.

Your data
  - It lives in the « data » folder, NEXT TO Proprietas.exe.
  - Backing up = copying the « data » folder (USB stick, external drive…).
  - Never separate the executable from its « data » folder: they go
    together.

Windows / antivirus
  - The application is not digitally signed: on first launch, Windows may
    show a warning (« Windows protected your PC »). Click « More info »
    then « Run anyway ».
  - If your antivirus flags it, allow it on the device: it is a false
    positive (open-source application, no telemetry).

Good to know
  - Experimental application, provided as a demonstration: it does not
    constitute legal advice and is not guaranteed to comply with current
    legislation. Consult a professional for legal questions.
  - Updating: download the new version and replace Proprietas.exe (keep
    your « data » folder).
  - Source code: https://github.com/LostInTheBugs/Proprietas

Enjoy!
